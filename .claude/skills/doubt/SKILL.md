# Doubt

Do an adversarial review, as if you wanted to defend the opposite thesis, before taking a decision that can cause consequences. Long sessions make unquestioned facts feel unquestionable — and that goes wrong very fast precisely when course correction is still cheap.

## When to use

- Before a high-consequence decision (killing an NPC, closing a plot line, changing a rule interpretation, rewriting an existing session).
- For any non-trivial decision inside a spec (spec-skeptic step of the pipeline).

## Process

1. **State the decision** in one sentence, plus what it assumes to be true.
2. **Steelman the opposite**: write the strongest honest case for NOT doing it (or doing the reverse).
3. **List what would have to be true** for the opposing case to win.
4. **Check the evidence**: verify those assumptions against the data — session boards, players board, bestiary, the rulebook PDF. Do not rely on conversation memory for facts that live in files.
5. **Verdict**: proceed as planned · adjust the decision · ask the GM. State which, and why, in two or three sentences.
